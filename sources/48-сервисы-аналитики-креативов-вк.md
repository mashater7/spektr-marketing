# Сервисы для поиска креативов конкурентов в VK Рекламе

> **Продолжение проверки от 1 ноября:** Это обзор состояния на 30 октября. Позднее Barkov был запущен: в журнале 49 записаны 18 результатов и 3 доступные карточки 2023 года. Сбой AdSpoiler 30 октября не определяет его сегодняшнее состояние. Сводка и ограничения: [64](64-вк-сообщества-конкурентов-и-реклама.md).

**Проверено 30.10.2026.** Рассматриваются объявления/промопосты конкурентов, а не собственная статистика кабинета. Цены и покрытие приведены по открытым страницам самих сервисов; платные кабинеты не подключались.

## Короткий вывод

AdSpoiler заявляет подходящую базу и недорогой поиск, но **не рекомендую пользоваться им, пока не восстановится API**: при проверке 30.10.2026 публичные страницы открывались, а при переходе к авторизации Playwright зафиксировал HTTP 504 на `api.adspoiler.com`. Поисковый запрос тоже не дал результата. Нельзя сейчас считать сервис рабочим только по его лендингу.

Следующий кандидат для практической проверки — **VK.Barkov.net**: его страница поиска открылась, и сервис заявляет поддержку универсальных промопостов из нового и старого рекламных кабинетов. Для сбора нужен вход через VK ID; я его не выполнял. TargetHunter тоже годится как запасной вариант, но его инструменты поиска объявлений ограничены старым кабинетом VK. В этом проходе общая публичная выдача свежих объявлений конкурентов не получена; отсутствие такой возможности вообще не установлено. Ни у одного из трёх сервисов не нашел публично описанного MCP/API-интерфейса или уведомлений, гарантирующих ежедневную подборку пяти новых примеров.

## Существенные ограничения и надежность выводов

- **TargetHunter:** сам сервис указывает, что оба инструмента для промопостов ограничены старыми рекламными кабинетами ВКонтакте. В анализе по группам посты связываются с датой создания, а не обязательно с датой фактического показа; охват не отображается, а VK устанавливает дневной лимит. Поэтому свежесть и полнота ежедневной выборки не гарантированы.
- **AdSpoiler:** «переходы» доступны только по коротким ссылкам vk.cc с открытой статистикой; это не внутренняя статистика рекламного кабинета. Продуктовая страница говорит о крупной базе и долгой истории, но публичных сведений о методе обновления, полном охвате форматов и API не нашел. Внешнее отраслевое описание отмечает, что объявления, ведущие на лид-формы, могут не попадать; это ограничение не подтверждено на официальной тарифной странице, поэтому считать нужно как риск, а не установленную гарантию.
- **Пять примеров в день:** вручную или через регулярный просмотр результатов это правдоподобный объем, но это не обещание сервисов. Чтобы получать ровно пять новых примеров ежедневно без ручного входа, потребуется либо проверить наличие закрытой интеграции у поставщика, либо построить собственную автоматизацию браузера после доступа к сервису. Автоматический сбор через официальный VK Ads API даст только данные подключенного кабинета и не является решением для конкурентного мониторинга.
- Во VK, по ранее изученным материалам проекта, публичной библиотеки объявлений нет; обычная стена сообщества показывает только публичные посты, не все таргетированные объявления.

## Рекомендация

1. **AdSpoiler пока отложить** до восстановления `api.adspoiler.com`; видимая проблема касается авторизации/данных, хотя маркетинговые страницы загружаются.
2. Следующим проверить **VK.Barkov.net** на двух-трех известных сообществах из списка проекта, сначала без оплаты, затем оценить полноту и свежесть выдачи. Сервис требует VK ID для запуска сбора; не авторизовываться от имени пользователя без его участия.
3. **TargetHunter держать запасным** источником для исторических промопостов старого кабинета, не считать его полным мониторингом современной VK Рекламы.
4. Автоматическую ежедневную подборку ровно пяти примеров пока считать неподтвержденной: сервисы не документируют доступный MCP/API/уведомления, которые это гарантируют.

## Стартовый набор поиска для «Спектра»

Первый ручной прогон в AdSpoiler «Таргетинг» — пять запросов по основным услугам:

1. `техническое обеспечение мероприятий`
2. `аренда звука на мероприятие`
3. `звук и свет на мероприятие`
4. `аренда светодиодного экрана`
5. `генератор на мероприятие`

Из результатов ежедневно сохранять до пяти новых релевантных креативов. Для каждого отмечать дату обнаружения, рекламодателя/сообщество, текст и визуальный хук, оффер, подтверждение, CTA, ссылку или форму назначения, видимые реакции и источник. Удалять дубли и помечать случаи, где размещение рекламное, но относится к соседней услуге. Не считать реакции или длительность показа доказательством конверсии.
