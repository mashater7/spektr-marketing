# Meta Ad Library по семантике сайта: есть ли там реклама московских event-подрядчиков

Проверка 28.10.2026. Без входа, свой headless-браузер (Python Playwright, chromium.launch() без профиля, один экземпляр, паузы 4–10 с). Скрины — `скрины-реклама/meta-semantika/`.

## Что сделано и что нет

Работа идёт. Файл дописывается по ходу.

## Журнал прогона

- Пробный запрос «аренда звука», все страны: Meta показывает «~4 600», без входа загрузилось 30 карточек, 15 прокруток ничего не добавили.
- Причина: запрос подгрузки следующей страницы (AdLibrarySearchPaginationQuery) без входа возвращает ошибку «Rate limit exceeded». Глубже первых 30 карточек Facebook не пускает. Каждый запрос всё равно пробует прокрутить три раза и записывает, что ответил сервер.
- Поэтому основной режим для фраз из нескольких слов — точная фраза (keyword_exact_phrase): выдача короче и почти целиком влезает в 30 карточек.
